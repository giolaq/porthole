# Development history

`CODEX_PLAN.md` briefed the original CLI, preview, MCP, and skill implementation. It shipped in the first Porthole release, with implementation from `1458f9a` through `40a5441`.

`CODEX_PLAN_2.md` asked for verification fixes, MJPEG fallback, and agent reliability tools. These shipped in 0.1.0, from `dcfa6bf` through `40a5441`.

`CODEX_PLAN_3.md` covered gestures, screen assertions, TV focus navigation, MP4 recording, multi-device sessions, and the GitHub Action. These shipped in 0.2.0, from `0db951f` through `c8032d2`.

`VEGA_EXPLORATION.md` records the Fire TV Vega simulator investigation and input experiments. Vega support shipped in 0.3.0, from `56a8891` through `6a8b82c`.

`ADR-MJPEG.md` records the screenshot-polling decision for MJPEG fallback. The implementation shipped in 0.1.0, from `dcfa6bf` through `40a5441`.
